# Communicating with the User

Skill-creator users range from first-time terminal users to
computer-literate developers. Pay attention to context cues to
calibrate phrasing.

- "evaluation" and "benchmark" are borderline jargon, but OK by
  default.
- "JSON" and "assertion" need serious cues that the user knows them
  before using them without explanation.
- When in doubt, briefly explain the term inline; a short definition
  costs little and keeps the user in the loop.
- Default to plain language; escalate precision only when the user
  demonstrates fluency.
